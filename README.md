# Hook Mixer (Junction)

Сайт, який бере випадкове відео й випадковий хук з Google Drive і поєднує їх через ffmpeg.
ffmpeg працює **прямо у браузері** (ffmpeg.wasm), тому сервер не потрібен, і безкоштовного Vercel достатньо.

## Як влаштовані папки на Google Drive
На сайті вказується **одна головна папка** (за замовчуванням уже стоїть папка Junction).
Всередині неї сайт сам шукає підпапки: з «хук»/«hook» у назві = хуки, з «відео»/«video» = відео.
Якщо вгадав неправильно, папки можна вибрати зі списку.
Якщо підпапок немає, відео з «hook»/«хук» у назві файлу вважаються хуками, а решта основними відео.

- **Папка з хуками** містить:
  - відео-хуки: короткі кліпи `.mp4/.mov`, які ставляться на початок;
  - текстові хуки: файл `.txt` або Google Doc, **один хук на рядок**. Текст накладається титром на перші 3 секунди.
- **Папка з відео** містить основні відео.
- Підпапки теж читаються (до 2 рівнів вкладеності).
- Обидві папки: Поділитися → «Усі, хто має посилання» → Читач.

## Підключення Drive через Apps Script (рекомендовано, без карти й ключів)
1. Відкрий script.google.com → **New project** (Новий проєкт).
2. Видали весь код у редакторі й встав вміст файлу `apps-script.gs` з цієї папки. Натисни 💾 (Save).
3. **Deploy → New deployment** → шестерня ⚙️ → **Web app**.
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Натисни **Deploy**.
4. Google попросить дозвіл: Authorize access → обери свій акаунт → Advanced → Go to project (unsafe) → Allow.
   («unsafe» тут означає лише, що скрипт не перевіряла Google; це твій власний скрипт.)
5. Скопіюй **Web app URL** (закінчується на `/exec`) і встав на сайті в перше поле.

Скрипт віддає тільки файли з головної папки Junction, тому решта твого Drive недоступна. Папку не треба робити публічною.
Великі відео скрипт передає частинами по 8 МБ, тому розмір файлу не обмежений (але великі файли довше вантажаться).

### Як оновити код скрипта (зберігши те саме посилання)
1. На script.google.com заміни весь код новим вмістом `apps-script.gs` і збережи.
2. Угорі у списку функцій обери `authorize` → натисни ▶ **Виконати (Run)** → дай нові дозволи (Додатково → Перейти до проєкту → Дозволити).
3. **Розгорнути → Керувати розгортаннями** → ✏️ (олівець) → Версія: **Нова версія** → **Розгорнути**.
Посилання `/exec` залишиться тим самим.

## Альтернатива: Google API-ключ (один раз, безкоштовно, карта не потрібна)
1. console.cloud.google.com → створи проєкт (наприклад, `hook-mixer`).
2. APIs & Services → Library → **Google Drive API** → Enable.
3. APIs & Services → Credentials → Create credentials → **API key**.
4. Відкрий ключ і налаштуй обмеження:
   - Application restrictions → Websites → додай `https://ТВІЙ-ПРОЄКТ.vercel.app/*` (і `http://localhost:*/*` для тестів);
   - API restrictions → Restrict key → Google Drive API.
5. Встав ключ на сайті в поле «Google API-ключ». Він зберігається тільки у твоєму браузері й **не потрапляє в GitHub**.

## Як користуватись
1. Встав ключ і посилання на дві папки → «Завантажити список файлів».
2. Обери параметри: скільки відео в ролику, скільки роликів, тип хука, якість.
3. «Поєднати» → перегляд → «Завантажити MP4».

Вкладка «Файли з компʼютера» робить те саме без Google Drive.

## Налаштування монтажу (блок «2. Стиль монтажу»)
Усе обирається на сайті й запамʼятовується у браузері.
- **Пресети**: TikTok жовтий, Хайп, Кіно, Мінімал, Junction. Можна зберегти свій.
- **Шрифт**: 11 шрифтів з кирилицею (Montserrat, Unbounded, Rubik, Oswald, Russo One, Manrope, Exo 2, Comfortaa, Caveat, Lobster, Press Start 2P).
- **Текст**: колір, стиль (плашка / обводка / тінь / без фону), колір плашки, розмір, позиція, ВЕЛИКІ ЛІТЕРИ, тривалість текстового хука.
- **Анімація**: статично, плавна поява, pop, виїзд знизу, по рядках, по одному слову.
- **Субтитри**: без субтитрів / з файлу `.srt` (з тією ж назвою, що й відео: `video1.mp4` + `video1.srt`) / **автоматично**.
  Автосубтитри розпізнають голос моделлю Whisper прямо у браузері (безкоштовно, без ключів). Перший раз завантажується модель: «Швидка» ≈130 МБ, «Точна» ≈250 МБ, потім вона береться з кешу.
  Можна вибрати мову, скільки слів показувати одночасно і колір підсвітки слова, яке звучить.
  Під готовим роликом є посилання «Субтитри (.srt)»: завантаж, виправ помилки і поклади файл поруч із відео на Drive. Наступного разу візьмуться виправлені субтитри.
- **Переходи**: різкий склей, випадковий, згасання, через чорний, спалах, свайп вліво/вгору, зум-ін, плавний зсув, коло, пікселі, розмиття + тривалість.
- **Ефекти**: 9 кольорокорекцій, зум-удар і тряска на хуку, віньєтка, зерно плівки, різкість, прогрес-бар.
- **Звук**: фонова музика (підпапка `music` на Drive або свій файл), гучність музики / оригіналу / ефектів, 9 звукових ефектів (на переході, на старті хука, на появі тексту), вирівнювання гучності.
- **Формат**: 9:16, 4:5, 1:1, 16:9; обрізати / розмитий фон / чорні смуги; швидкість 1–1.5×; 1080p; менший розмір файлу.
- **CTA і лого**: заклик до дії в кінці, логотип (підпапка `logo` на Drive або свій PNG), позиція, розмір, прозорість.
- Кнопка **«Показати превʼю кадру»** показує, як виглядатиме текст і стиль, ще до монтажу.

### Підпапки на Google Drive
`hook` — хуки (відео, фото, .txt), `body` — основні відео (+ .srt), `music` — треки, `logo` — логотип. Назви можна змінити: сайт вгадує їх за словами і дає вибрати вручну.

### Звідки шрифти і звуки
Шрифти — Google Fonts (ліцензія SIL OFL, див. `fonts/LICENSE.txt`). Звукові ефекти в `sfx/` синтезовані з нуля, тож вільні для використання.

## Обмеження
- Обробка йде на твоєму компʼютері: 720p працює швидко, 1080p повільніше. Довгі відео (кілька хвилин) обрізай полем «Макс. секунд».
- Загальний обсяг файлів на один ролик має бути не більше ~1 ГБ (ліміт памʼяті браузера).
- Перше натискання завантажує ffmpeg (~30 МБ). Далі браузер бере його з кешу.
