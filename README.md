# Hook Mixer (Junction)

Сайт, який бере випадкове відео й випадковий хук з Google Drive і поєднує їх через ffmpeg.
ffmpeg працює **прямо у браузері** (ffmpeg.wasm), тому сервер не потрібен, і безкоштовного Vercel достатньо.

## Як влаштовані папки на Google Drive
На сайті вказується **одна головна папка** (за замовчуванням уже стоїть папка Junction).
Всередині неї сайт сам шукає підпапки: з «хук»/«hook» у назві = хуки, з «відео»/«video» = відео.
Якщо вгадав неправильно, папки можна вибрати зі списку.
Якщо підпапок немає, відео з «hook»/«хук» у назві файлу вважаються хуками, а решта основними відео.

- **Папка з хуками** містить:
  - відео-хуки: короткі кліпи `.mp4/.mov`, які ставляться на початок;
  - текстові хуки: файл `.txt` або Google Doc, **один хук на рядок**. Текст накладається титром на перші 3 секунди.
- **Папка з відео** містить основні відео.
- Підпапки теж читаються (до 2 рівнів вкладеності).
- Обидві папки: Поділитися → «Усі, хто має посилання» → Читач.

## Google API-ключ (один раз, безкоштовно)
1. console.cloud.google.com → створи проєкт (наприклад, `hook-mixer`).
2. APIs & Services → Library → **Google Drive API** → Enable.
3. APIs & Services → Credentials → Create credentials → **API key**.
4. Відкрий ключ і налаштуй обмеження:
   - Application restrictions → Websites → додай `https://ТВІЙ-ПРОЄКТ.vercel.app/*` (і `http://localhost:*/*` для тестів);
   - API restrictions → Restrict key → Google Drive API.
5. Встав ключ на сайті в поле «Google API-ключ». Він зберігається тільки у твоєму браузері й **не потрапляє в GitHub**.

## Як користуватись
1. Встав ключ і посилання на дві папки → «Завантажити список файлів».
2. Обери параметри: скільки відео в ролику, скільки роликів, тип хука, якість.
3. «Поєднати» → перегляд → «Завантажити MP4».

Вкладка «Файли з компʼютера» робить те саме без Google Drive.

## Обмеження
- Обробка йде на твоєму компʼютері: 720p працює швидко, 1080p повільніше. Довгі відео (кілька хвилин) обрізай полем «Макс. секунд».
- Загальний обсяг файлів на один ролик має бути не більше ~1 ГБ (ліміт памʼяті браузера).
- Перше натискання завантажує ffmpeg (~30 МБ). Далі браузер бере його з кешу.
